# Мой кампус

## Локальный запуск

Установи Node.js 22 или 24. Открой терминал в распакованной папке mgimo-sqlite и выполни команды по очереди.

```sh
npm ci
npm run setup
npm start
```

Открой http://localhost:3000 и войди под своим существующим логином. Самостоятельная регистрация закрыта.

## Файлы проекта

Интерфейс находится в public/, сервер — в server.js. В university.db сохранены пользователи и профили. Скрипт setup.js создаёт локальный файл .env при первом запуске.

Команда npm test запускает проверки на отдельной временной базе.

## Перенос проекта

В архив входит полная база с четырьмя аккаунтами. Для первой установки распакуй архив в отдельную папку. При обновлении действующего сайта сохрани его текущую базу: она может содержать более свежие данные. Для хранения проекта вместе с базой на GitHub используй приватный репозиторий.
